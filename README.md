# Deep Learning Tablet Labs

Two hands-on labs with Streamlit apps that run on a tablet over the local network.

| Lab | What it does | Folder |
|---|---|---|
| Handwritten digit recognition | CNN trained on MNIST recognizes a digit drawn on the tablet | [`mnist_streamlit_lab/`](mnist_streamlit_lab/) |
| Signature verification | Checks whether a signature is genuine or forged, using a person's enrolled references; Siamese CNN training on CEDAR in Colab | [`signature_verification_lab/`](signature_verification_lab/) |

See each folder's README for setup and usage.
