# Handwritten Digit Recognition — Deep Learning Lab

**Objective:** train a CNN on MNIST, evaluate it, and deploy an interactive Streamlit application for handwritten digit recognition on a tablet.

## Requirements
- Python 3.11 or 3.12 recommended
- Internet access for the first MNIST dataset download and package installation
- A tablet/phone/laptop web browser. The tablet is only the input device; TensorFlow runs on the host machine/server.

## Setup (Windows PowerShell)
```powershell
cd mnist_streamlit_lab
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python train.py
streamlit run app.py --server.address 0.0.0.0
```

## Setup (macOS/Linux)
```bash
cd mnist_streamlit_lab
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python train.py
streamlit run app.py --server.address 0.0.0.0
```

## Using a tablet
1. Connect tablet and host computer to the **same Wi-Fi network**.
2. Note the host's local IP (on Windows: `ipconfig`).
3. On the tablet, open `http://HOST_IP:8501` (replace HOST_IP with the PC's local IPv4 address).
4. Draw a digit and press Recognize. Use the canvas toolbar to clear it.
5. Allow inbound TCP port 8501 through the PC firewall **on your trusted private network only** if necessary. Do not expose the port publicly.

Alternative: deploy the code and trained `.keras` model to a supported Streamlit hosting platform; tablet can then access its HTTPS URL. TensorFlow resource limits may vary by host.

## Google Colab training option
Open `MNIST_CNN_Lab.ipynb` in Google Colab and run all cells. Download `mnist_cnn.keras` and place it at `model/mnist_cnn.keras` in this folder. Colab is for model training; the Streamlit interface must run on a separate reachable machine or hosting provider. 

## Files
- `MNIST_CNN_Lab.ipynb`: teaching notebook with EDA, architecture, metrics and export.
- `train.py`: training from command line.
- `preprocessing.py`: crop, resize and recenter drawings to 28×28.
- `app.py`: tablet-friendly Streamlit app.
- `requirements.txt`: Python dependencies.
- `TP_students.md`: lab tasks and reflection questions.

## Expected outcomes
The CNN often exceeds 98% accuracy on the *MNIST held-out test set* with this design, but this is not a measured result for this package. Check your own evaluation output. Accuracy on live tablet handwriting can be considerably lower because the handwriting distribution differs.

## Notes
- The `.keras` trained model is **not shipped**; it is generated by running the training script or notebook.
- The app uses `streamlit-drawable-canvas` v0.13.0; it requires Streamlit >= 1.53 and Python >= 3.10.
